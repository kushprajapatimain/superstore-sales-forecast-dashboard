# 📊 Superstore Sales Forecast & Analysis Dashboard (Power BI)

An interactive **Power BI Dashboard** designed to analyze U.S. Superstore sales, regional performance, category trends, and a **15-day sales forecast** using time-series analytics.

---

## 🎯 Objective

To analyze historical sales data and generate a reliable **15-day sales forecast**, enabling smarter planning, stock management, and strategic decision-making.

---

## 🔎 Overview

This end-to-end Power BI project includes:

- Data transformation (Power Query)
- Data modeling
- KPI creation using DAX
- 15-day forecasting
- Full interactive dashboard

---

## 📈 Key KPIs

| KPI | Value | Description |
|------|--------|-------------|
| **Total Sales** | 1.57M | Total revenue |
| **Total Profit** | 175K | Profit earned |
| **Quantity Sold** | 22K | Total units sold |
| **Avg Delivery Days** | 4 days | Avg shipping duration |
| **Forecast (Next 15 Days)** | ~3K/day | Predicted daily sales |

## 🧠 Key Insights

- **California & New York** contribute highest sales  
- **Office Supplies** dominates category revenue  
- **Standard Class** is the most preferred shipping mode  
- Forecast shows **consistent average daily sales (~3K/day)**  
- Top sub-categories include **Phones, Chairs, Binders**
